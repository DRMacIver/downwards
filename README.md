# Downwards

Downwards is an early-stage, no-combat roguelike metroidvania platformer.

It's almost entirely vibecoded, but with heavy human-in-the-loop feedback on design,
game directions, etc. It's an attempt to make exactly the sort of game that I want to play
over and over again, although my tastes are  not especially eclectic, so I imagine it
will appeal to others too.

### Playing the game

Right now the game has no official releases, so you can only play by running the development version
by cloning the repo, cding to the directory, and running `cargo run`. It has only been tested on
a mac at the moment, though in theory should work on other OSes too.
