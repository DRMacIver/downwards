# tide-shaft-a -- easy variant of "Tide Shaft (rising/falling hazard tide)".
#
# A ceiling-to-floor shaft crossed by three FULL-WIDTH hazard bands that light
# in sequence from top to bottom, so the lit band visibly marches down the
# room like a falling tide. There is no shutter to squeeze through and no
# wall to climb: every band spans all 32 columns, so the only question the
# room ever asks is WHEN, never where.
#
# The easy expression of the class is not "fewer/wider ledges" -- it is that
# the safe pockets are made structural. Each band's row also carries the
# landing ledge for that tier, so the tiles you stand on are the LIP of the
# tide: standing on a ledge is always survivable, and the tide only ever
# threatens you in mid-transit. That turns the room into a read-the-cadence
# drill with generous forgiveness, instead of a reaction test. A player who
# simply waits on each ledge for the band below to go dark, then drops, walks
# the whole shaft without ever touching a hazard.
#
# The ledges zigzag left/right/left with 20-30px rises and horizontal overlaps
# at every seam, so the same staircase is walkable in both directions. Ascent
# is the same clock read backwards -- you chase the tide up instead of riding
# it down -- which is the class's "tide direction" axis expressed inside one
# room rather than across variants.
door ceiling
door floor
# The tide. Three bands, one period, phases spaced a third apart so exactly
# one band is lit at a time and the lit band steps downward every 60 ticks
# (one second). 55/180 duty = the shaft is clear two thirds of the time.
# Rects are inset 1px inside their tile row so the ledge lips at that row are
# the waterline: you can stand on the lip, you cannot swim through the band.
