# Shutter Chute, hard variant: a serpentine descent chute.
#
# Three fall lanes alternate right / left / right down the shaft. Each lane is
# crossed by a shutter band that spans the WHOLE lane, so there is no way round
# one - only a way through it in time. The only staging posts are two-tile nubs
# hung just above each band, so a player who breaks the descent into stages
# still has to cross that band on the very next beat; there is no ledge where
# the clock stops. The bands run as a downward-travelling wave (phases 0/22/44
# of a 90-tick period), so the expert line is one unbroken release from the
# ceiling that threads all three, while the cautious line stages nub to nub and
# pays a beat at each.
#
# The twist is the last beat. Instead of a fourth band across the fall, the
# room ends in a standing-height shutter curtain 8 tiles wide (cols 17-24) with
# a 40-tick clear window across the only run-in to the exit door. Walking 80px
# does not fit 40 ticks; a dash does. So the chute is dash-gated at its floor,
# and the final commitment happens on the ground, in full view, after three
# committed falls - the room's tightest beat is also its most readable one.
