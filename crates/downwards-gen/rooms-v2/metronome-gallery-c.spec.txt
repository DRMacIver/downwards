# metronome-gallery-c -- HARD variant of "Metronome Gallery".
#
# THE FOLDED WAVE. Six floor-to-ceiling curtains (cols 5, 9, 14, 18, 22, 27)
# cut the corridor into seven bays. The phase march is a palindrome:
# 0 / 20 / 40 / 40 / 20 / 0. The safe opening rolls EAST out of the west door,
# hits the mirror at the middle of the room, and rolls back WEST. So whichever
# door you enter by, you ride the wave for the first half of the gallery and
# then run flat out against it for the second half -- the hard expression of
# the class is not "more curtains, faster", it is that the cadence reverses
# under you at the pivot and everything you learned about launching on the beat
# inverts mid-room. Same room, two tempos, one trip.
#
# ACTIVE WINDOW EXCEEDS HALF THE PERIOD: 48 lit of 90. Every curtain is lethal
# more often than it is safe, which is the class's stated hard end. There is
# still not one spike in the room and not one gap wider than a walk: the floor
# is unbroken solid at row 17 and every bay crossing is a 30-50px flat run.
# Danger is 100% temporal.
#
# THE SHARED PHASE. Curtains 3 and 4 (cols 14 and 18) hold the SAME phase, so
# the pivot bay (cols 15-17, three tiles) opens and shuts as a single door.
# It cannot be used as a rest bay: you must enter and clear it inside one
# window, arriving already committed. That is the two-alcoves-in-one-window
# axis, and it sits exactly on the fold so the pivot is also where the march
# reverses -- the room's hardest beat and its thesis in the same three tiles.
#
# THE SHALLOW STEP. Bay cols 19-21 is a raised one-tile step (row 16). It is
# the only bay east of the fold narrow enough to be a perch rather than a rest,
# and it is where the reversed wave first bites.
